# decodelabs-cyber-project1
Password Strength Checker 🔐

I created this project using Python to check the strength of a password. The program takes a password as input and checks its length, uppercase and lowercase letters, numbers, and special characters. Based on these checks, it classifies the password as Weak, Medium, or Strong.

The project also includes additional features such as detecting repeated characters, identifying common passwords, calculating a security score, and providing suggestions to improve password strength. It also allows users to check multiple passwords while keeping the password hidden during input.

Through this project, I learned about Python string handling, conditional statements, loops, functions, and regular expressions. This project helped me improve my programming skills and understand the importance of creating strong and secure passwords.
